   - `spec.source.repoURL`: `{{ index .Values "intel-gpu-device-plugin" "chart" "repo" }}`
   - `spec.source.chart`: `{{ index .Values "intel-gpu-device-plugin" "chart" "name" }}`
   - `spec.source.targetRevision`: `{{ index .Values "intel-gpu-device-plugin" "chart" "version" }}`
   - `spec.source.helm.releaseName`: `intel-gpu-device-plugin`
   - `spec.source.helm.values` (inline YAML string):
     ```

     nodeFeatureRule: true
     sharedDevNum: 1
     enableMonitoring: true
     ```
   - `spec.destination.server`: `https://kubernetes.default.svc`
   - `spec.destination.namespace`: `{{ index .Values "intel-gpu-device-plugin" "namespace" }}`
   - `spec.syncPolicy` (identical to NVIDIA):
     - `automated: {prune: true, selfHeal: true}`

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-04-01 | Tampering | GPU_VENDOR value in helm-addons.tmpl | mitigate | Schema validates GPU_VENDOR against closed enum (none/nvidia/intel) before template rendering; `eq` function performs strict string equality |
| T-04-02 | Elevation of Privilege | intel-device-plugins namespace | accept | PodSecurity `privileged` labels required for GPU device access; only one GPU namespace active at a time via mutual exclusion |
| T-04-03 | Information Disclosure | Intel Helm chart registry URL in values.yaml | accept | Public registry URL; no credentials stored; standard Helm chart source |
</threat_model>
